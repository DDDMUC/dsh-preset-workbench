# cetacea（鲸鱼娘）预设

角色扮演预设。改提示词有两种方式：

1. **设置 → 预设工作台**（推荐）：界面里选预设、逐段编辑提示词、用勾选框控制每一段是否生效（不勾选 = 不进入系统提示词），保存后新开会话生效。
2. 直接改文件：提示词按段落存在 `section.*.md`，清单在 `sections.json`（`enabled: false` 即关闭该段）。

| 文件 | 作用 | 需要你动吗 |
| --- | --- | --- |
| section.*.md + sections.json | 提示词分段本体 | 用工作台改最方便 |
| persona.md | 旧版单文件提示词，仅作备份 | 可不管 |
| agent.cordis.yml | 组合：挂哪些工具、压缩策略 | 一般不动 |
| persona-file.mjs | 装载脚本：按清单拼装提示词 | 不要动 |
| preset.yml | 选择器里显示的名字和简介 | 想改名时改 |

新建自己的预设：直接在 预设工作台 里"新建"，它会以本预设为模板复制一份（自带分段装载器）。

人格开关：会话里发【TIMEOUT_SIGNAL】退出角色扮演，发【PERSONA_LOAD】恢复。
